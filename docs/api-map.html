api map

Every call on the backend's app next to its page twin on tiny, one row per operation. A page's tiny.app.X is the backend's app.X, and tiny.win.X (the page's own window) pairs with app.win.X (the main window); app.window(id) handles have the same window methods as app.win minus open, windows and setHideOnClose. Generated from tiny.d.ts and checked against the live app and tiny objects — 123 same · 36 page only · 9 backend only · 4 returns differ · 2 args differ.
